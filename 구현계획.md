# TabBouncer — Chrome 광고 팝업 탭/창 자동 종료 프로그램

**통합 설계 · 구현 문서 (v2.0)**

| 항목 | 내용 |
|---|---|
| 프로젝트명 | **TabBouncer** (초대받지 않은 탭을 문 밖으로) |
| 대상 환경 | Windows 11 + Google Chrome (Stable 136 이상 기준) |
| 최종 채택 구현 | C# / .NET 8, **단일 파일**, CDP(Chrome DevTools Protocol) 방식 |
| 참고 구현 | Chrome 확장(MV3) + 네이티브 메시징 호스트(Go 또는 C#) |
| 외부 의존성 | 없음 (BCL의 `ClientWebSocket` + `System.Text.Json`만 사용) |

---

## 0. 원래 요구사항

특정 사이트에서 어떤 동작을 하면 광고가 새로운 탭이나 웹브라우저 창으로 생성되어 몹시 불편하다. 이렇게 생성되는 탭이나 창을 자동으로 종료시켜 주는 프로그램을 만들고 싶다. Windows 11에서 Chrome을 사용하며, 가능하면 Go나 C#으로 구현한다. → 이후 **C#**, **단일 파일** 소스로 확정.

## 1. 문제 정의와 메커니즘 분석

자동 종료 로직을 설계하려면 "무엇을 탐지할 것인가"를 먼저 정확히 알아야 한다. 이런 광고 팝업이 만들어지는 대표적 패턴은 다음과 같다.

| 패턴 | 설명 | 탐지 단서 |
|---|---|---|
| **Pop-under / window.open** | 클릭 핸들러에서 `window.open()` 호출. 사용자 제스처가 있으므로 Chrome 기본 팝업 차단을 통과한다 | opener(부모 탭)가 존재, 생성 시각이 클릭 직후 |
| **`<a target="_blank">` 오버레이** | 투명 레이어에 광고 링크를 깔아둠 | 새 탭, opener 존재, 도메인이 원본과 다름 |
| **about:blank 후 리다이렉트** | 먼저 `about:blank`로 열고 JS로 광고 URL로 이동 | 생성 시 URL이 `about:blank`, 직후 외부 도메인으로 내비게이션 |
| **`window.open(...,'width=..,height=..')`** | 별도 창(popup type) 생성 | 창 크기가 작고 일반 창이 아님 |
| **`noopener` 체인 / 중간 리다이렉터** | 광고망 트래커 → 최종 랜딩 | 리다이렉트 체인 길이 2 이상, 첫 홉이 알려진 광고 도메인 |

핵심 신호는 결국 세 가지다. **(a) opener의 존재와 그 부모 탭의 도메인**, **(b) 새 탭/창의 최종 URL 도메인**, **(c) 생성 타이밍**. 이 세 가지를 얻을 수 있는 경로를 찾는 것이 아키텍처 선택의 전부다.

## 2. 구현 방식 비교와 최종 선택

### 2.1 후보 아키텍처

| # | 방식 | 정확도 | 안정성 | 단일 파일 가능 | 평소 프로필 사용 |
|---|---|---|---|---|---|
| **A** | Chrome 확장(MV3) + 네이티브 호스트(Go/C#) | ★★★★★ | ★★★★★ | ✕ (JS+manifest 필수) | ○ |
| **B** | **CDP 원격 제어 (C# 단독)** | ★★★★☆ | ★★★☆☆ | **○** | ✕ (전용 프로필) |
| **C** | Win32 창 감시(SetWinEventHook + UI Automation) | ★★☆☆☆ | ★★★☆☆ | ○ | ○ |
| **D** | 기존 광고차단기(uBlock Origin Lite 등) | ★★★☆☆ | ★★★★★ | — | ○ |

### 2.2 각 방식의 결정적 제약

**A안의 제약**: 정확도와 안정성은 최고이며 평소 쓰는 프로필을 그대로 감시할 수 있다. 그러나 확장은 `manifest.json` + JS 파일이 반드시 필요하므로 **C# 단일 파일 요구와 양립하지 않는다.** 또한 커맨드라인 `--load-extension` 플래그는 Chrome 137부터 브랜드 빌드에서 제거되어 스크립트 자동 로드가 불가능하고, `chrome://extensions` UI에서 수동 로드해야 한다.

**B안의 제약**: Chrome 136부터 `--remote-debugging-port` / `--remote-debugging-pipe` 스위치는 **기본 사용자 프로필 디렉터리에서는 무시된다.** (App-Bound Encryption 우회를 노린 정보탈취 악성코드의 쿠키 탈취 대응) 반드시 `--user-data-dir=<비표준 경로>`를 함께 줘야 하므로, 평소 프로필과 분리된 **전용 프로필**을 쓰게 된다.

**C안의 제약**: Chrome의 모든 창은 `Chrome_WidgetWin_1` 클래스이고 탭에는 윈도우 핸들이 아예 없다. 즉 새 "탭"은 Win32로 탐지 불가하고 새 "창"만 탐지 가능하다. URL도 UI Automation으로 주소창을 긁어야 하는데 느리고 깨지기 쉽다.

### 2.3 결론

**B안(CDP 단독, C# 단일 파일)을 최종 구현으로 채택한다.** C# 한 파일이라는 요구를 충족하는 유일한 고정확도 경로이며, 부수 효과로 **A안이 할 수 없는 일**을 하나 얻는다. `Target.setAutoAttach`의 `waitForDebuggerOnStart` 옵션으로 **새 탭이 스크립트를 단 한 줄도 실행하기 전에 일시정지**시켜 놓고 판정한 뒤 닫을 수 있어, 광고가 아예 렌더링되지 않는다.

A안은 §9에 참고 구현으로 남겨 둔다. 전용 프로필이 감수하기 어렵다면 그쪽으로 전환하면 된다.

### 4.2 참고안 (A: 확장 + 네이티브 호스트)

```
Chrome(평소 프로필)
 └ PopupGuard 확장(MV3 service worker)
     · chrome.tabs.onCreated / onUpdated
     · chrome.windows.onCreated
     · 1차 로컬 판정 → 즉시 tabs.remove
     · 애매한 건 네이티브 호스트에 질의
        │ Native Messaging (stdio, 4바이트 LE 길이 + UTF-8 JSON)
        ▼
   tabbouncer-host.exe (Go 또는 C#)
     · 규칙 엔진 / 로그 / 통계 / 설정 hot-reload
        │ Named Pipe
        ▼
   tabbouncer-tray.exe (선택) — 트레이 UI, Win32 폴백
```

호스트를 분리하는 이유는, MV3 서비스 워커가 유휴 시 종료되고 파일 시스템 접근이 없기 때문이다. 영구 로그, 사용자 편집 가능한 규칙 파일, 트레이 UI는 네이티브 쪽이 맞다. 네이티브 포트가 연결돼 있는 동안 서비스 워커가 살아 있게 유지되는 부수 효과도 있다.

## 5. 판정 엔진 설계

무조건 닫으면 정상 새 탭까지 죽는다. **점수제(scoring)** 로 설계한다.

### 5.1 수집 가능한 특징(feature)

| 특징 | CDP 출처 | 확장 출처 |
|---|---|---|
| 새 타깃 식별자 | `targetInfo.targetId` | `tabId`, `windowId` |
| opener 존재/식별자 | `targetInfo.openerId` | `tab.openerTabId` |
| opener URL | opener 타깃의 캐시된 `url` | `tabs.get(openerTabId).url` |
| 초기 URL | `targetCreated` 시점의 `url` | `tab.pendingUrl` |
| 최종 URL | `targetInfoChanged` / `Page.frameNavigated` | `tabs.onUpdated` |
| 창 유형/크기 | `Browser.getWindowForTarget().bounds` | `windows.get().type/width/height` |
| 백그라운드 생성 | (간접) | `tab.active === false` |
| 클릭→생성 Δt | 프로그램 기준 생성 시각 | content script의 클릭 타임스탬프 |
| 리다이렉트 체인 | `Page.frameNavigated` 횟수 | `webNavigation.onCommitted`의 `transitionQualifiers` |

### 5.2 룰셋

```
# 0단계: 범위 제한 (가장 중요한 안전장치)
if URL이 internal/blank                    → -999 (개입 안 함)
if 목적지가 whitelist 매칭                 → -999
if URL이 로그인/OAuth 패턴                 → -999
if opener가 watchedSites 밖 AND 목적지가 광고망 아님 AND !strictMode → -999
if opener 없음 AND 목적지가 광고망 아님    → -999   # 주소창 직접 입력

# 1단계: 가점/감점
+50  opener 호스트가 watchedSites 매칭
+40  목적지 eTLD+1 이 adDomains 매칭
+25  목적지 eTLD+1 ≠ opener eTLD+1  (크로스 사이트)
-30  목적지 eTLD+1 == opener eTLD+1 (같은 사이트)
+20  창 크기가 팝업급(가로<1000 또는 세로<780)
+20  opener 자체가 광고 도메인 (광고→광고 체인)
+15  초기 URL이 about:blank 였고 이후 외부 도메인으로 이동
+15  목적지 TLD가 스팸 다발 TLD (.top .xyz .buzz .click …)
+10  생성 후 1.5초 내 확정 (클릭 직후 열림)
+10  리다이렉트 체인 ≥ 2

# 2단계: 액션
score >= closeThreshold(기본 70)  → close
score >= closeThreshold - 30      → 회색지대: 로그만
그 외                              → keep
```

### 5.3 안전장치 (필수)

정상 탭을 잡아먹는 것이 이런 도구의 가장 큰 실패 모드라서 여러 겹으로 막는다.

가장 중요한 것은 위 0단계의 **범위 제한**이다. opener가 `watchedSites`에 있거나 목적지가 알려진 광고 도메인인 경우가 아니면 아예 점수 계산 없이 빠져나간다. 그 위에 **Dry-run 모드를 기본 초기값**으로 두어 며칠 관측 후 활성화하게 하고, **10초에 5건을 넘기면 스스로 Dry-run으로 후퇴**하며(오탐 폭주 방지), **창에 남은 마지막 일반 탭은 절대 닫지 않는다**(브라우저 통째 종료 사고 방지). 닫은 20건은 되돌릴 수 있고, 그 도메인을 즉시 화이트리스트에 넣을 수 있다. `chrome://*`, `chrome-extension://*`, `devtools://`, `file://`은 대상에서 원천 제외하며, 로그인·결제·OAuth 경로는 화이트리스트와 URL 패턴 검사로 이중 보호한다.

## 6. 최종 구현 — 단일 파일 C# 소스

```csharp
// =====================================================================================
//  TabBouncer  -  Chrome 광고 팝업 탭/창 자동 종료기 (Windows 11 / .NET 8 / 단일 파일)
//
//  동작 원리
//    1) 전용 프로필로 Chrome 을 --remote-debugging-port 와 함께 실행(또는 이미 켜진 것에 접속)
//    2) 브라우저 레벨 WebSocket 에 붙어 Target 도메인 이벤트를 구독
//    3) 새 page 타깃이 생기면 (opener / URL / 창 크기 / 타이밍) 점수를 매김
//    4) 임계값 이상이면 Target.closeTarget 으로 즉시 종료, 원래 탭으로 포커스 복귀
//    5) PreemptiveBlock 이 켜져 있으면 스크립트 실행 전에 정지시킨 상태로 판정 → 광고 렌더링 0
//
//  빌드
//    dotnet new console -n TabBouncer
//    (생성된 Program.cs 를 이 파일로 교체)
//    dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
//
//  키 조작 (실행 중)
//    d = Dry-run 토글   p = 일시중지/재개   u = 마지막 차단 되돌리기
//    l = 최근 차단 목록  w = 화이트리스트 추가  r = 설정 다시 읽기   q = 종료

internal sealed class CdpClient : IAsyncDisposable
{
    private readonly ClientWebSocket _ws = new();
    private readonly SemaphoreSlim _sendLock = new(1, 1);
    private readonly ConcurrentDictionary<int, TaskCompletionSource<JsonNode?>> _pending = new();
    private int _nextId;
    private CancellationTokenSource? _loopCts;

    /// <summary>(method, params, sessionId)</summary>
    public event Action<string, JsonNode?, string?>? EventReceived;
    public event Action<Exception?>? Closed;

    public async Task ConnectAsync(string wsUrl, CancellationToken ct)
    {
        _ws.Options.KeepAliveInterval = TimeSpan.FromSeconds(30);
        await _ws.ConnectAsync(new Uri(wsUrl), ct).ConfigureAwait(false);
        _loopCts = CancellationTokenSource.CreateLinkedTokenSource(ct);
        _ = Task.Run(() => ReceiveLoopAsync(_loopCts.Token));
    }

    public async Task<JsonNode?> SendAsync(string method, JsonObject? prms = null,
                                           string? sessionId = null, int timeoutMs = 5000)
    {
        int id = Interlocked.Increment(ref _nextId);
        var msg = new JsonObject { ["id"] = id, ["method"] = method };
        if (prms is not null) msg["params"] = prms;
        if (sessionId is not null) msg["sessionId"] = sessionId;

        var tcs = new TaskCompletionSource<JsonNode?>(TaskCreationOptions.RunContinuationsAsynchronously);
        _pending[id] = tcs;

        byte[] bytes = Encoding.UTF8.GetBytes(msg.ToJsonString());
        await _sendLock.WaitAsync().ConfigureAwait(false);
        try
        {
            if (_ws.State != WebSocketState.Open) throw new InvalidOperationException("websocket closed");
            await _ws.SendAsync(bytes, WebSocketMessageType.Text, true, CancellationToken.None)
                     .ConfigureAwait(false);
        }
        finally { _sendLock.Release(); }

        using var timeout = new CancellationTokenSource(timeoutMs);
        timeout.Token.Register(() => { if (_pending.TryRemove(id, out var t)) t.TrySetCanceled(); });
        return await tcs.Task.ConfigureAwait(false);
    }

    /// <summary>실패해도 무시하는 fire-and-forget 전송.</summary>
    public void Fire(string method, JsonObject? prms = null, string? sessionId = null)
        => _ = SendAsync(method, prms, sessionId).ContinueWith(_ => { }, TaskContinuationOptions.OnlyOnFaulted);

    private async Task ReceiveLoopAsync(CancellationToken ct)
    {
        var buf = new byte[64 * 1024];
        var ms = new MemoryStream();
        Exception? fault = null;
        try
        {
            while (!ct.IsCancellationRequested && _ws.State == WebSocketState.Open)
            {
                ms.SetLength(0);
                WebSocketReceiveResult res;
                do
                {
                    res = await _ws.ReceiveAsync(buf, ct).ConfigureAwait(false);
                    if (res.MessageType == WebSocketMessageType.Close)
                        throw new WebSocketException("closed by peer");
                    ms.Write(buf, 0, res.Count);
                } while (!res.EndOfMessage);

                JsonNode? node;
                try { node = JsonNode.Parse(Encoding.UTF8.GetString(ms.GetBuffer(), 0, (int)ms.Length)); }
                catch { continue; }
                if (node is null) continue;

                var idNode = node["id"];
                if (idNode is not null)
                {
                    int id = idNode.GetValue<int>();
                    if (_pending.TryRemove(id, out var tcs))
                    {
                        var err = node["error"];
                        if (err is not null) tcs.TrySetException(new Exception(err.ToJsonString()));
                        else tcs.TrySetResult(node["result"]);
                    }
                }
                else
                {
                    string? method = node["method"]?.GetValue<string>();
                    if (method is not null)
                        EventReceived?.Invoke(method, node["params"], node["sessionId"]?.GetValue<string>());
                }
            }
        }
        catch (OperationCanceledException) { }
        catch (Exception ex) { fault = ex; }
        finally
        {
            foreach (var kv in _pending) kv.Value.TrySetCanceled();
            _pending.Clear();
            Closed?.Invoke(fault);
        }
    }

    public async ValueTask DisposeAsync()
    {
        try { _loopCts?.Cancel(); } catch { }
        try
        {
            if (_ws.State == WebSocketState.Open)
                await _ws.CloseAsync(WebSocketCloseStatus.NormalClosure, "bye", CancellationToken.None);
        }
        catch { }
        _ws.Dispose();
    }
}

    private static async Task RunSessionAsync(CancellationToken ct)
    {
        string? wsUrl = await ProbeBrowserWsAsync(_cfg.DebugPort, ct);

        if (wsUrl is null)
        {
            if (!_cfg.AutoLaunchChrome)
                throw new Exception($"127.0.0.1:{_cfg.DebugPort} 에 디버깅 가능한 Chrome 이 없습니다.");
            LaunchChrome();
            for (int i = 0; i < 40 && wsUrl is null; i++)
            {
                await Task.Delay(500, ct);
                wsUrl = await ProbeBrowserWsAsync(_cfg.DebugPort, ct);
            }
            if (wsUrl is null) throw new Exception("Chrome 디버깅 포트 연결 실패(타임아웃).");
        }
        else Info("이미 실행 중인 디버깅 Chrome 에 접속합니다.");

        _targets.Clear();
        _watch.Clear();

        var cdp = new CdpClient();
        _cdp = cdp;
        var done = new TaskCompletionSource();
        cdp.Closed += ex =>
        {
            Warn("브라우저 연결이 끊어졌습니다." + (ex is null ? "" : " (" + ex.Message + ")"));
            done.TrySetResult();
        };
        cdp.EventReceived += OnCdpEvent;

        await cdp.ConnectAsync(wsUrl, ct);
        Ok("브라우저에 연결되었습니다.");

        await cdp.SendAsync("Target.setDiscoverTargets", new JsonObject { ["discover"] = true });
        if (_cfg.PreemptiveBlock)
        {
            await cdp.SendAsync("Target.setAutoAttach", new JsonObject
            {
                ["autoAttach"] = true,
                ["waitForDebuggerOnStart"] = true,
                ["flatten"] = true
            });
            Info("선차단(preemptive) 모드 활성: 새 탭은 스크립트 실행 전에 검사됩니다.");
        }

        using (ct.Register(() => done.TrySetResult()))
            await done.Task;

        _cdp = null;
        await cdp.DisposeAsync();
    }

    private static async Task<string?> ProbeBrowserWsAsync(int port, CancellationToken ct)
    {
        try
        {
            using var http = new HttpClient { Timeout = TimeSpan.FromSeconds(2) };
            string json = await http.GetStringAsync($"http://127.0.0.1:{port}/json/version", ct);
            return JsonNode.Parse(json)?["webSocketDebuggerUrl"]?.GetValue<string>();
        }
        catch { return null; }
    }

    private static void LaunchChrome()
    {
        string exe = ResolveChromePath();
        string profile = string.IsNullOrWhiteSpace(_cfg.UserDataDir)
            ? Path.Combine(DataDir, "ChromeProfile")
            : _cfg.UserDataDir;
        Directory.CreateDirectory(profile);

        var psi = new ProcessStartInfo(exe) { UseShellExecute = true };

        psi.ArgumentList.Add("--restore-last-session");
        if (!string.IsNullOrWhiteSpace(_cfg.StartUrl)) psi.ArgumentList.Add(_cfg.StartUrl);

        Info($"Chrome 실행: {exe}");
        Info($"전용 프로필: {profile}");
        Process.Start(psi);

    private static string ResolveChromePath()
    {
        if (!string.IsNullOrWhiteSpace(_cfg.ChromePath) && File.Exists(_cfg.ChromePath))
            return _cfg.ChromePath;

        string[] candidates =
        {
            Path.Combine(Environment.GetEnvironmentVariable("ProgramFiles") ?? "",
                         @"Google\Chrome\Application\chrome.exe"),
            Path.Combine(Environment.GetEnvironmentVariable("ProgramFiles(x86)") ?? "",
                         @"Google\Chrome\Application\chrome.exe"),
            Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData),
                         @"Google\Chrome\Application\chrome.exe"),
        };
        foreach (var c in candidates)
            if (!string.IsNullOrEmpty(c) && File.Exists(c)) return c;

        throw new FileNotFoundException(
            "chrome.exe 를 찾을 수 없습니다. config.json 의 chromePath 를 직접 지정하세요.");
    }

    // ---------------------------------------------------------------- CDP 이벤트

    private static void OnCdpEvent(string method, JsonNode? p, string? sessionId)
    {
        try
        {
            switch (method)
            {
                case "Target.targetCreated":
                case "Target.targetInfoChanged":
                {
                    var ti = p?["targetInfo"];
                    if (ti is null) break;
                    string id = ti["targetId"]!.GetValue<string>();
                    var rec = _targets.GetOrAdd(id, _ => new TargetRec { TargetId = id });
                    rec.Type = ti["type"]?.GetValue<string>() ?? "";
                    rec.Url = ti["url"]?.GetValue<string>() ?? "";
                    string? opener = ti["openerId"]?.GetValue<string>();
                    if (!string.IsNullOrEmpty(opener)) rec.OpenerId = opener;

                    if (rec.Type != "page") break;

                    if (method == "Target.targetCreated")
                    {
                        // 선차단 모드에서는 attachedToTarget 이 판정을 주도하므로 여기서는 등록만.
                        _watch.TryAdd(id, new PageCtx
                        {
                            TargetId = id,
                            OpenerId = rec.OpenerId,
                            InitialUrl = rec.Url,
                            CreatedAt = Now
                        });
                    }
                    else if (_watch.TryGetValue(id, out var ctx))
                    {
                        ctx.OpenerId ??= rec.OpenerId;
                        if (!IsBlank(rec.Url)) _ = EvaluateAsync(ctx, "infoChanged");
                    }
                    break;
                }

                case "Target.attachedToTarget":
                {
                    var ti = p?["targetInfo"];
                    string? sid = p?["sessionId"]?.GetValue<string>();
                    bool waiting = p?["waitingForDebugger"]?.GetValue<bool>() ?? false;
                    if (ti is null || sid is null) break;

                    string id = ti["targetId"]!.GetValue<string>();
                    string type = ti["type"]?.GetValue<string>() ?? "";
                    string url = ti["url"]?.GetValue<string>() ?? "";
                    string? opener = ti["openerId"]?.GetValue<string>();

                    var rec = _targets.GetOrAdd(id, _ => new TargetRec { TargetId = id });
                    rec.Type = type; rec.SessionId = sid;
                    if (!string.IsNullOrEmpty(url)) rec.Url = url;
                    if (!string.IsNullOrEmpty(opener)) rec.OpenerId = opener;

                    if (type != "page") { if (waiting) Resume(sid); break; }

                    var ctx = _watch.GetOrAdd(id, _ => new PageCtx
                    {
                        TargetId = id, OpenerId = rec.OpenerId,
                        InitialUrl = rec.Url, CreatedAt = Now
                    });
                    ctx.OpenerId ??= rec.OpenerId;

                    if (!waiting) break;

                    ctx.PausedSessionId = sid;
                    ctx.PausedAt = Now;

                    // 정지 상태에서 즉시 판정. 반드시 빠르게 끝내고 풀어줘야 한다.
                    _ = Task.Run(async () =>
                    {
                        try
                        {
                            bool closed = await EvaluateAsync(ctx, "preempt");
                            if (closed) return;

                            // about:blank 로 시작하는 팝언더는 리다이렉트를 조기에 잡기 위해 Page 이벤트 구독
                            if (IsBlank(ctx.InitialUrl) && _cdp is not null)
                                _cdp.Fire("Page.enable", null, sid);
                        }
                        finally { Resume(sid); ctx.PausedSessionId = null; }
                    });
                    break;
                }

                case "Page.frameNavigated":
                {
                    // 선차단 모드에서 about:blank → 광고 URL 로 넘어가는 순간을 잡는다.
                    var frame = p?["frame"];
                    if (frame is null) break;
                    if (frame["parentId"] is not null) break;            // 최상위 프레임만
                    string url = frame["url"]?.GetValue<string>() ?? "";
                    if (IsBlank(url) || sessionId is null) break;

                    var hit = _targets.Values.FirstOrDefault(t => t.SessionId == sessionId);
                    if (hit is null) break;
                    hit.Url = url;
                    if (_watch.TryGetValue(hit.TargetId, out var ctx))
                    {
                        ctx.Redirects++;
                        _ = EvaluateAsync(ctx, "frameNavigated");
                    }
                    break;
                }

                case "Target.targetDestroyed":
                {
                    string? id = p?["targetId"]?.GetValue<string>();
                    if (id is null) break;
                    _targets.TryRemove(id, out _);
                    _watch.TryRemove(id, out _);
                    break;
                }

                case "Target.detachedFromTarget":
                {
                    string? sid = p?["sessionId"]?.GetValue<string>();
                    if (sid is null) break;
                    foreach (var t in _targets.Values) if (t.SessionId == sid) t.SessionId = null;
                    break;
                }
            }
        }
        catch (Exception ex) { Err("이벤트 처리 오류(" + method + "): " + ex.Message); }
    }

    private static void Resume(string sessionId)
        => _cdp?.Fire("Runtime.runIfWaitingForDebugger", null, sessionId);

    // ---------------------------------------------------------------- 스위퍼

    private static async Task SweeperLoopAsync(CancellationToken ct)
    {
        while (!ct.IsCancellationRequested)
        {
            try
            {
                long now = Now;
                foreach (var ctx in _watch.Values.ToArray())
                {
                    // 안전장치: 정지 상태가 1.2초를 넘으면 무조건 풀어준다(탭이 멈추는 것을 방지).
                    if (ctx.PausedSessionId is { } sid && now - ctx.PausedAt > 1200)
                    {
                        Resume(sid);
                        ctx.PausedSessionId = null;
                    }
                    if (ctx.Decided == 0 && now - ctx.CreatedAt >= _cfg.DebounceMs)
                        await EvaluateAsync(ctx, "debounce");
                    if (now - ctx.CreatedAt > 15000)
                        _watch.TryRemove(ctx.TargetId, out _);
                }
            }
            catch { }
            try { await Task.Delay(200, ct); } catch { break; }
        }
    }

    // ---------------------------------------------------------------- 판정

    /// <returns>실제로 닫았으면 true</returns>
    private static async Task<bool> EvaluateAsync(PageCtx ctx, string stage)
    {
        if (!_cfg.Enabled || _cdp is null) return false;
        if (ctx.Decided != 0) return false;

        string url = _targets.TryGetValue(ctx.TargetId, out var self) ? self.Url : ctx.InitialUrl;
        string openerUrl = ctx.OpenerId is not null && _targets.TryGetValue(ctx.OpenerId, out var op)
                           ? op.Url : "";

        // 창 크기 조회는 비용이 있으므로 debounce 단계에서 한 번만
        if (stage == "debounce" && !ctx.WindowChecked)
        {
            ctx.WindowChecked = true;
            try
            {
                var r = await _cdp.SendAsync("Browser.getWindowForTarget",
                            new JsonObject { ["targetId"] = ctx.TargetId }, null, 1500);
                var b = r?["bounds"];
                int w = b?["width"]?.GetValue<int>() ?? 0;
                int h = b?["height"]?.GetValue<int>() ?? 0;
                if (w > 0 && h > 0 && (w < 1000 || h < 780)) ctx.PopupLikely = true;
            }
            catch { }
        }

        var (score, reason) = Score(url, openerUrl, ctx);

        if (score <= -900) { if (stage == "debounce") Interlocked.Exchange(ref ctx.Decided, 1); return false; }

        if (score >= _cfg.CloseThreshold - 30)
            WriteEventLog(new
            {
                stage, score, reason, url, openerUrl,
                initialUrl = ctx.InitialUrl, popupLikely = ctx.PopupLikely,
                redirects = ctx.Redirects, ageMs = Now - ctx.CreatedAt
            });

        if (score < _cfg.CloseThreshold)
        {
            if (score >= _cfg.CloseThreshold - 30)
                Console.WriteLine($"  · 회색지대 {score,3}점 [{reason}] {Trim(url)}");
            return false;
        }

        if (Interlocked.Exchange(ref ctx.Decided, 1) != 0) return false;

        if (_cfg.DryRun)
        {
            Warn($"[DRY-RUN] 차단 대상 {score}점 [{reason}] {Trim(url)}");
            return false;
        }
        if (!AllowRate())
        {
            _cfg.DryRun = true;
            Err($"10초 내 {_cfg.MaxClosesPerWindow}건 초과 → 안전을 위해 DRY-RUN 으로 전환했습니다.");
            return false;
        }

        // 마지막 남은 일반 탭이면 닫지 않는다(브라우저 자체가 종료되는 것 방지).
        int normalPages = _targets.Values.Count(t => t.Type == "page" && !IsInternal(t.Url));
        if (normalPages <= 1) { Warn("마지막 탭이므로 닫지 않습니다: " + Trim(url)); return false; }

        try
        {
            await _cdp.SendAsync("Target.closeTarget",
                new JsonObject { ["targetId"] = ctx.TargetId }, null, 3000);

            lock (_recentClosed)
            {
                _recentClosed.Insert(0, new ClosedItem(url, openerUrl, score, reason, DateTime.Now));
                if (_recentClosed.Count > 20) _recentClosed.RemoveRange(20, _recentClosed.Count - 20);
            }
            Ok($"닫음 {score}점 [{reason}] {Trim(url)}");
            WriteEventLog(new { stage = "closed", score, reason, url, openerUrl });

            if (_cfg.RefocusOpener && ctx.OpenerId is not null)
                _cdp.Fire("Target.activateTarget", new JsonObject { ["targetId"] = ctx.OpenerId });

            return true;
        }
        catch (Exception ex) { Err("닫기 실패: " + ex.Message); return false; }
    }

    private static (int score, string reason) Score(string url, string openerUrl, PageCtx ctx)
    {
        if (string.IsNullOrWhiteSpace(url) || IsInternal(url)) return (-999, "internal");
        if (IsBlank(url)) return (-999, "blank-pending");

        string h = HostOf(url);
        string oh = HostOf(openerUrl);
        if (h.Length == 0) return (-999, "no-host");
        if (Match(h, _cfg.Whitelist)) return (-999, "whitelist");
        if (LooksLikeAuth(url)) return (-999, "auth-flow");

        bool watchedOpener = oh.Length > 0 && Match(oh, _cfg.WatchedSites);
        bool adDomain = Match(h, _cfg.AdDomains);

        // ★ 최우선 안전장치: 감시 사이트에서 열렸거나, 목적지가 알려진 광고망일 때만 개입한다.
        if (!watchedOpener && !adDomain && !_cfg.StrictMode)
            return (-999, "not-in-scope");
        if (string.IsNullOrEmpty(oh) && !adDomain)
            return (-999, "no-opener");          // 사용자가 직접 주소를 입력해 연 탭

        int s = 0;
        var why = new List<string>();

        if (watchedOpener) { s += 50; why.Add("watched-opener"); }
        if (adDomain) { s += 40; why.Add("ad-domain"); }

        if (oh.Length > 0)
        {
            if (!Etld1(h).Equals(Etld1(oh), StringComparison.OrdinalIgnoreCase))
            { s += 25; why.Add("cross-site"); }
            else { s -= 30; why.Add("same-site"); }
        }

        if (ctx.PopupLikely) { s += 20; why.Add("popup-window"); }
        if (oh.Length > 0 && Match(oh, _cfg.AdDomains)) { s += 20; why.Add("ad-chain"); }
        if (IsBlank(ctx.InitialUrl)) { s += 15; why.Add("blank-then-redirect"); }
        if (_cfg.SuspiciousTlds.Contains(TldOf(h), StringComparer.OrdinalIgnoreCase))
        { s += 15; why.Add("suspicious-tld"); }
        if (Now - ctx.CreatedAt < 1500) { s += 10; why.Add("fast-open"); }
        if (ctx.Redirects >= 2) { s += 10; why.Add("redirect-chain"); }

        return (s, string.Join("+", why));
    }

    private static bool AllowRate()
    {
        long now = Now;
        while (_closeStamps.TryPeek(out long t) && now - t > _cfg.RateWindowMs) _closeStamps.TryDequeue(out _);
        if (_closeStamps.Count >= _cfg.MaxClosesPerWindow) return false;
        _closeStamps.Enqueue(now);
        return true;
    }

    // ---------------------------------------------------------------- URL 유틸

    private static string HostOf(string raw)
    {
        if (string.IsNullOrEmpty(raw)) return "";
        int i = raw.IndexOf("://", StringComparison.Ordinal);
        if (i < 0) return "";
        string s = raw[(i + 3)..];
        int j = s.IndexOfAny(new[] { '/', '?', '#' });
        if (j >= 0) s = s[..j];
        int at = s.LastIndexOf('@');
        if (at >= 0) s = s[(at + 1)..];
        if (!s.Contains(']'))
        {
            int c = s.LastIndexOf(':');
            if (c >= 0) s = s[..c];
        }
        return s.ToLowerInvariant();
    }

    private static readonly HashSet<string> SecondLevel = new(StringComparer.OrdinalIgnoreCase)
    { "co", "com", "ne", "net", "or", "org", "go", "ac", "gov", "edu", "pe", "re", "kg", "ms", "sc", "hs" };

    /// <summary>간이 eTLD+1. 완벽하지 않지만 kr/uk/jp 등 2단계 TLD 대부분을 커버한다.</summary>
    private static string Etld1(string host)
    {
        var p = host.Split('.');
        if (p.Length >= 3 && p[^1].Length == 2 && SecondLevel.Contains(p[^2]))
            return string.Join('.', p[^3..]);
        return p.Length >= 2 ? string.Join('.', p[^2..]) : host;
    }

    private static string TldOf(string host)
    {
        int i = host.LastIndexOf('.');
        return i < 0 ? "" : host[(i + 1)..];
    }

    private static bool Match(string host, IEnumerable<string> list)
    {
        if (string.IsNullOrEmpty(host)) return false;
        foreach (var raw in list)
        {
            var d = raw?.Trim().TrimStart('*', '.').ToLowerInvariant();
            if (string.IsNullOrEmpty(d)) continue;
            if (host == d || host.EndsWith("." + d, StringComparison.Ordinal)) return true;
        }
        return false;
    }

    private static bool IsBlank(string u)
        => string.IsNullOrEmpty(u) || u.StartsWith("about:", StringComparison.OrdinalIgnoreCase);

    private static bool IsInternal(string u)
        => IsBlank(u)
        || u.StartsWith("chrome://", StringComparison.OrdinalIgnoreCase)
        || u.StartsWith("chrome-extension://", StringComparison.OrdinalIgnoreCase)
        || u.StartsWith("chrome-untrusted://", StringComparison.OrdinalIgnoreCase)
        || u.StartsWith("devtools://", StringComparison.OrdinalIgnoreCase)
        || u.StartsWith("edge://", StringComparison.OrdinalIgnoreCase)
        || u.StartsWith("file://", StringComparison.OrdinalIgnoreCase);

    private static bool LooksLikeAuth(string url)
    {
        string lower = url.ToLowerInvariant();
        return lower.Contains("/oauth") || lower.Contains("/authorize")
            || lower.Contains("/signin") || lower.Contains("/login")
            || lower.Contains("/sso") || lower.Contains("saml");
    }

    private static string Trim(string s, int n = 96)
        => s.Length <= n ? s : s[..n] + "…";

    // ---------------------------------------------------------------- 설정 / 로그

    }

    // ---------------------------------------------------------------- 콘솔 UI

    private static void KeyLoop()
    {
        while (!_appCts.IsCancellationRequested)
        {
            ConsoleKeyInfo k;
            try { k = Console.ReadKey(true); }
            catch { return; }     // 콘솔이 리다이렉트된 환경

            switch (char.ToLowerInvariant(k.KeyChar))
            {
                case 'q': _appCts.Cancel(); return;

                case 'd':
                    _cfg.DryRun = !_cfg.DryRun;
                    Info($"DRY-RUN {(_cfg.DryRun ? "ON (닫지 않음)" : "OFF (실제로 닫음)")}");
                    break;

                case 'p':
                    _cfg.Enabled = !_cfg.Enabled;
                    Info($"감시 {(_cfg.Enabled ? "재개" : "일시중지")}");
                    break;

                case 'r': LoadOrCreateConfig(); Info("설정 재적용 완료"); break;

                case 'l':
                    lock (_recentClosed)
                    {
                        if (_recentClosed.Count == 0) { Info("최근 차단 내역이 없습니다."); break; }
                        Console.WriteLine("  ── 최근 차단 ──");
                        for (int i = 0; i < _recentClosed.Count; i++)
                        {
                            var c = _recentClosed[i];
                            Console.WriteLine($"   [{i}] {c.At:HH:mm:ss} {c.Score,3}점 " +
                                              $"[{c.Reason}] {Trim(c.Url, 80)}");
                        }
                    }
                    break;

                case 'u':
                {
                    ClosedItem? item = null;
                    lock (_recentClosed)
                        if (_recentClosed.Count > 0) { item = _recentClosed[0]; _recentClosed.RemoveAt(0); }
                    if (item is null) { Info("되돌릴 항목이 없습니다."); break; }
                    _cdp?.Fire("Target.createTarget",
                        new JsonObject { ["url"] = item.Url, ["newWindow"] = false });
                    Info("되돌림: " + Trim(item.Url));
                    break;
                }

                case 'w':
                {
                    string? host = null;
                    lock (_recentClosed) if (_recentClosed.Count > 0) host = HostOf(_recentClosed[0].Url);
                    if (host is null) { Info("화이트리스트에 추가할 대상이 없습니다."); break; }
                    string d = Etld1(host);
                    if (!_cfg.Whitelist.Contains(d, StringComparer.OrdinalIgnoreCase))
                    {
                        _cfg.Whitelist.Add(d);
                        SaveConfig();
                        Ok($"화이트리스트 추가: {d}");
                    }
                    else Info($"이미 화이트리스트에 있습니다: {d}");
                    break;
                }
            }
        }
    }

    private static void Line(ConsoleColor c, string tag, string msg)
    {
        lock (_logLock)
        {
            Console.ForegroundColor = c;
            Console.Write($"[{DateTime.Now:HH:mm:ss}] {tag} ");
            Console.ResetColor();

        }
    }

    private static void Warn(string m) => Line(ConsoleColor.Yellow, "!", m);

}
```

## 8. 구현상 특별히 신경 쓴 부분

**선차단(preemptive) 모드의 위험 관리.** `waitForDebuggerOnStart`는 **모든** 새 탭을 정지시키므로, 판정 로직이 늦어지면 사용자가 직접 연 탭도 멈춘 것처럼 보인다. 그래서 판정은 네트워크 호출 없는 순수 계산으로만 하고, `finally`에서 무조건 `Runtime.runIfWaitingForDebugger`를 호출하며, 그것마저 실패한 경우를 대비해 스위퍼 루프가 1.2초 넘게 정지된 세션을 강제로 풀어준다. 창 크기 조회처럼 왕복이 필요한 작업은 정지 상태가 아닌 debounce 단계로 미룬다.

**about:blank 팝언더 대응.** 생성 시 URL이 `about:blank`면 판정을 미루고 `Page.enable`로 해당 세션의 내비게이션을 구독한다. 이후 `Page.frameNavigated`가 최상위 프레임에서 외부 도메인을 알려주는 순간 즉시 재판정한다. 동시에 `debounceMs`(기본 1500ms) 타이머가 백스톱으로 동작한다.

**중복 처리 방지.** 하나의 타깃에 대해 `targetCreated`, `attachedToTarget`, `targetInfoChanged`, `frameNavigated`, `debounce` 등 여러 경로로 판정이 들어올 수 있으므로 `Interlocked.Exchange(ref ctx.Decided, 1)`로 실제 액션은 정확히 한 번만 실행된다.

**연결 복원력.** Chrome을 사용자가 종료하면 WebSocket이 끊기고 `Closed` 이벤트가 세션 루프를 깨운다. 메인 루프는 5초 후 재탐색·재실행을 시도하므로, 프로그램을 켜 둔 채로 Chrome을 마음대로 껐다 켜도 된다.

```js
const DEFAULTS = {
  enabled: true, dryRun: true, strictMode: false, closeThreshold: 70,
  watchedSites: [], adDomains: [], whitelist: ["accounts.google.com"],
  useNativeHost: true, rateLimit: { windowMs: 10000, max: 5 }
};
let cfg = { ...DEFAULTS };
const pending = new Map();
const lastClick = new Map();     // tabId -> {ts, userIntent}
const exempt   = new Map();      // Ctrl+클릭 등 사용자 의도 면제
let recentClosed = [], closeTimestamps = [];

const host = u => { try { return new URL(u).hostname; } catch { return ""; } };
function base(h) {
  const p = h.split("."), two = new Set(["co","com","ne","or","go","ac","gov","edu"]);
  return (p.length >= 3 && two.has(p[p.length-2])) ? p.slice(-3).join(".") : p.slice(-2).join(".");
}
const matchList = (h, list) => !!h && list.some(d => h === d || h.endsWith("." + d));

// ---- 네이티브 호스트 ----
let port = null; const waiters = new Map(); let seq = 0;
function connectHost() {
  if (!cfg.useNativeHost) return;
  try {
    port = chrome.runtime.connectNative("com.tabbouncer.host");
    port.onMessage.addListener(msg => {
      if (msg.type === "config") { cfg = { ...cfg, ...msg.config }; return; }
      const w = waiters.get(msg.id);
      if (w) { waiters.delete(msg.id); clearTimeout(w.t); w.resolve(msg); }
    });
    port.onDisconnect.addListener(() => { port = null; setTimeout(connectHost, 5000); });
    port.postMessage({ type: "hello", version: chrome.runtime.getManifest().version });
  } catch { port = null; }
}
function askHost(payload, timeoutMs = 300) {
  if (!port) return Promise.resolve(null);
  const id = ++seq;
  return new Promise(resolve => {
    const t = setTimeout(() => { waiters.delete(id); resolve(null); }, timeoutMs);
    waiters.set(id, { resolve, t });
    port.postMessage({ ...payload, id });
  });
}

// ---- 클릭 신호 ----
chrome.runtime.onMessage.addListener((m, sender) => {
  if (m?.type !== "click" || !sender.tab) return;
  lastClick.set(sender.tab.id, { ts: Date.now(), userIntent: !!m.userIntent });
  if (m.userIntent) exempt.set(sender.tab.id, Date.now() + 5000);   // 5초간 면제
});

// ---- 탭 생성 ----
chrome.tabs.onCreated.addListener(async tab => {
  if (!cfg.enabled) return;
  const ctx = {
    tabId: tab.id, windowId: tab.windowId, createdAt: Date.now(),
    openerTabId: tab.openerTabId ?? null,
    initialUrl: tab.pendingUrl || tab.url || "",
    active: tab.active, openerUrl: "", windowType: "", finalUrl: "",
    redirects: 0, dtClick: Infinity, exempt: false
  };
  if (ctx.openerTabId != null) {
    const ex = exempt.get(ctx.openerTabId);
    if (ex && ex > Date.now()) ctx.exempt = true;          // Ctrl+클릭 등
    try { const op = await chrome.tabs.get(ctx.openerTabId);
          ctx.openerUrl = op.url || op.pendingUrl || ""; } catch {}
    const c = lastClick.get(ctx.openerTabId);
    if (c) ctx.dtClick = ctx.createdAt - c.ts;
  }
  try { const w = await chrome.windows.get(tab.windowId);
        ctx.windowType = w.type; ctx.winSize = { w: w.width, h: w.height }; } catch {}

  pending.set(tab.id, ctx);
  await evaluate(ctx, "onCreated");
  setTimeout(() => { if (pending.has(tab.id)) evaluate(pending.get(tab.id), "timeout"); }, 1500);
  setTimeout(() => pending.delete(tab.id), 8000);
});

chrome.tabs.onUpdated.addListener((tabId, info, tab) => {
  const ctx = pending.get(tabId); if (!ctx) return;
  if (info.url || info.status === "loading") {
    ctx.finalUrl = tab.pendingUrl || tab.url || ctx.finalUrl;
    if (ctx.finalUrl && !ctx.finalUrl.startsWith("about:")) evaluate(ctx, "onUpdated");
  }
});

chrome.webNavigation.onCommitted.addListener(d => {
  if (d.frameId !== 0) return;
  const ctx = pending.get(d.tabId); if (!ctx) return;
  if (d.transitionQualifiers?.some(q => q.includes("redirect"))) ctx.redirects++;
});

chrome.tabs.onRemoved.addListener(id => {
  pending.delete(id); lastClick.delete(id); exempt.delete(id);
});

// ---- 점수 ----
function score(ctx) {
  const url = ctx.finalUrl || ctx.initialUrl;
  const h = host(url), oh = host(ctx.openerUrl);
  if (!url || url.startsWith("chrome://") || url.startsWith("chrome-extension://")) return -999;
  if (ctx.exempt) return -999;
  if (matchList(h, cfg.whitelist)) return -999;

  let s = 0;
  if (oh && matchList(oh, cfg.watchedSites)) s += 50;
  else if (!cfg.strictMode) return -999;

  if (matchList(h, cfg.adDomains)) s += 40;
  if (h && oh && base(h) !== base(oh)) s += 25; else s -= 30;
  if (ctx.windowType === "popup") s += 20;
  if (ctx.active === false) s += 15;
  if (!ctx.initialUrl || ctx.initialUrl.startsWith("about:")) s += 15;
  if (ctx.dtClick < 1500) s += 10;
  if (ctx.redirects >= 2) s += 10;
  return s;
}

// ---- 판정/실행 ----
async function evaluate(ctx, stage) {
  if (ctx.done) return;
  let s = score(ctx), reason = `local(${stage})`;
  if (s > -900 && s < cfg.closeThreshold && s >= cfg.closeThreshold - 40) {
    const r = await askHost({ type: "evaluate", ctx });
    if (r && typeof r.score === "number") { s = r.score; reason = "host:" + (r.reason || ""); }
  }
  port?.postMessage({ type: "log", entry: { ...ctx, stage, score: s, reason } });
  if (s < cfg.closeThreshold) return;
  ctx.done = true;
  if (cfg.dryRun) return notify("(관측 모드) 차단 대상", ctx.finalUrl || ctx.initialUrl);
  if (!allowRate()) { cfg.dryRun = true; return notify("차단 급증", "관측 모드로 전환합니다."); }
  await closeTab(ctx, s, reason);
}

function allowRate() {
  const now = Date.now();
  closeTimestamps = closeTimestamps.filter(t => now - t < cfg.rateLimit.windowMs);
  if (closeTimestamps.length >= cfg.rateLimit.max) return false;
  closeTimestamps.push(now); return true;
}

async function closeTab(ctx, s, reason) {
  const url = ctx.finalUrl || ctx.initialUrl;
  try {
    try { await chrome.tabs.update(ctx.tabId, { url: "about:blank" }); } catch {}  // beforeunload 회피
    await chrome.tabs.remove(ctx.tabId);
  } catch {
    try {
      const w = await chrome.windows.get(ctx.windowId, { populate: true });
      if (w.tabs.length <= 1 && w.type === "popup") await chrome.windows.remove(ctx.windowId);
    } catch {}
  }
  recentClosed.unshift({ url, opener: ctx.openerUrl, score: s, reason, at: Date.now() });
  recentClosed = recentClosed.slice(0, 20);
  await chrome.storage.local.set({ recentClosed });
  port?.postMessage({ type: "closed", url, opener: ctx.openerUrl });
  if (ctx.openerTabId != null) {
    try {
      const op = await chrome.tabs.get(ctx.openerTabId);
      await chrome.windows.update(op.windowId, { focused: true });
      await chrome.tabs.update(op.id, { active: true });
    } catch {}
  }
}

function notify(title, message) {
  chrome.notifications.create({ type: "basic", iconUrl: "icon128.png", title, message: message || "" });
}

chrome.runtime.onStartup.addListener(init);
chrome.runtime.onInstalled.addListener(init);
async function init() {
  const st = await chrome.storage.sync.get("cfg");
  cfg = { ...DEFAULTS, ...(st.cfg || {}) };
  connectHost();
}
init();
```

### 9.3 호스트 프레이밍 코드

**C#** — 판정 로직(`Score`, `HostOf`, `Etld1`, `Match`)은 §6의 것을 그대로 재사용하고, 입출력만 아래로 바꾼다.

```csharp
static Stream _in = Console.OpenStandardInput();
static Stream _out = Console.OpenStandardOutput();

static byte[]? ReadMessage()
{
    var len = new byte[4];
    if (!ReadExact(len, 4)) return null;
    int n = BinaryPrimitives.ReadInt32LittleEndian(len);
    if (n <= 0 || n > 64 * 1024 * 1024) return null;
    var buf = new byte[n];
    return ReadExact(buf, n) ? buf : null;
}
static bool ReadExact(byte[] buf, int count)
{
    int off = 0;
    while (off < count) { int r = _in.Read(buf, off, count - off); if (r <= 0) return false; off += r; }
    return true;
}
static void Write(object o)
{
    var json = JsonSerializer.SerializeToUtf8Bytes(o);
    lock (_outLock)
    {
        var len = new byte[4];
        BinaryPrimitives.WriteInt32LittleEndian(len, json.Length);
```

**Go** — 동일 규격.

```go
func readMsg(r io.Reader) ([]byte, error) {
	var n uint32
	if err := binary.Read(r, binary.LittleEndian, &n); err != nil { return nil, err }
	if n == 0 || n > 64*1024*1024 { return nil, io.ErrUnexpectedEOF }
	buf := make([]byte, n)
	_, err := io.ReadFull(r, buf)
	return buf, err
}

func writeMsg(v interface{}) {
	b, err := json.Marshal(v); if err != nil { return }
	outMu.Lock(); defer outMu.Unlock()

	_, _ = os.Stdout.Write(b)
}
```

### 9.4 확장 설치와 ID 고정

`chrome://extensions` → 개발자 모드 ON → "압축해제된 확장 프로그램을 로드". 커맨드라인 `--load-extension` 플래그는 Chrome 137부터 브랜드 빌드에서 제거되었으므로 UI 로드 또는 정책 방식만 유효하다.

압축해제 확장은 경로에 따라 ID가 바뀌어 네이티브 메시징의 `allowed_origins`가 깨진다. 고정하려면 "확장 프로그램 압축"으로 `.crx` + `.pem`을 만들고, 공개키를 매니페스트 `key` 필드에 넣는다.

```powershell

```

재부팅 후에도 "개발자 모드 확장" 경고를 없애고 싶으면 `HKLM\SOFTWARE\Policies\Google\Chrome\ExtensionSettings` 정책으로 등록한다.

### 9.5 트레이 앱과 자동시작

네이티브 호스트는 Chrome이 켜질 때 Chrome이 직접 실행/종료하므로 자동시작 등록이 불필요하다. 상시 UI가 필요하면 별도 트레이 프로세스를 두고 Named Pipe(`\\.\pipe\tabbouncer`)로 통신한다. C#은 `NotifyIcon` + `ContextMenuStrip`, Go는 `getlantern/systray`를 쓴다. 트레이 앱만 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 또는 작업 스케줄러(로그온 트리거)에 등록한다.

## 12. 배포와 설치

**B안(채택)** — 배포물이 `tabbouncer.exe` 하나뿐이다. 아무 폴더에 두고 실행하면 `%LOCALAPPDATA%\TabBouncer\`에 설정·로그·전용 프로필이 자동 생성된다. 자동시작이 필요하면 작업 스케줄러에 로그온 트리거로 등록하거나 시작 프로그램 폴더(`shell:startup`)에 바로가기를 넣는다. 콘솔 창이 거슬리면 `--live` 인수를 준 바로가기의 실행 창 옵션을 "최소화"로 설정하거나, `<OutputType>WinExe</OutputType>` + 트레이 UI로 바꾼다.

**A안** — `install.ps1`이 (1) `C:\Program Files\TabBouncer\`에 호스트와 매니페스트 복사, (2) 매니페스트 `path` 치환, (3) `HKCU\...\NativeMessagingHosts\com.tabbouncer.host` 등록, (4) 기본 `config.json` 생성, (5) 확장 폴더 배치 및 UI 로드 안내, (6) 확장 ID 확인 후 `allowed_origins` 갱신, (7) 트레이 자동시작 등록 순으로 수행한다. `uninstall.ps1`은 역순 + 레지스트리 키 삭제.

## 15. 알려진 한계와 최종 권고

**전용 프로필**이 B안의 가장 큰 불편이다. 평소 프로필의 확장·비밀번호는 따라오지 않으며, Chrome이 "자동화된 소프트웨어에 의해 제어되고 있습니다" 배너를 띄울 수 있다(기능 영향 없음). 평소 프로필을 그대로 감시해야 하면 §9의 A안으로 전환해야 하고, 그때는 단일 파일 조건을 포기해야 한다.

**`Ctrl+클릭` 구분 불가**가 두 번째 한계다. CDP만으로는 사용자가 의도적으로 연 탭과 광고 팝업을 구분할 신호가 없어, 범위 제한과 광고 도메인 목록에 의존해 회피한다. 감시 사이트에서 외부 링크를 자주 새 탭으로 여신다면 그 도메인들을 `whitelist`에 넣어 두는 것이 좋다.

**`Etld1()`은 Public Suffix List 전체가 아닌 간이 구현**이라 `github.io` 같은 특수 케이스에서 부정확하다. 정확도가 문제가 되면 PSL 파일을 내려받아 파싱하는 로직으로 교체하면 되는데, 단일 파일 조건은 유지되지만 데이터 파일이 하나 늘어난다.

**보안 주의.** 디버깅 포트가 열린 Chrome은 로컬 프로세스라면 누구나 제어할 수 있다. `--remote-debugging-address=127.0.0.1` 바인딩을 반드시 유지하고, 중요한 계정으로 로그인하는 프로필과는 분리해서 쓰기를 권한다. Chrome이 136부터 이 제약을 만든 이유가 바로 이것이다.

마지막으로 실용적인 권고 하나. 이 프로그램을 돌리기 전에 전용 프로필에 uBlock Origin Lite를 먼저 설치해 보시길 권한다. 대부분의 pop-under는 이미 필터 목록에 잡혀 있어 그것만으로 끝나는 경우가 많고, 그러면 TabBouncer는 잔여 팝업만 처리하는 가벼운 보조 장치가 되어 룰셋도 단순해지고 오탐 걱정도 거의 사라진다.

그리고 이 도구는 **본인 PC의 본인 브라우저**를 대상으로만 사용하시기 바란다. 타인·공용 PC에 브라우저를 조작하는 상주 프로그램을 심는 것은 별개의 문제이며, 네이티브 메시징 호스트와 디버깅 포트는 잘못 쓰면 그 자체가 보안 취약점이 된다.
