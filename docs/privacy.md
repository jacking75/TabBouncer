# TabBouncer 개인정보 처리방침 / Privacy policy

최종 갱신일 / Last updated: 2026-10-09

## 한국어

TabBouncer는 Choi HeungBae(`jacking75`)가 제공하는 무료 오픈소스 Windows 앱이다. 별도 앱 계정, 구독, 앱 내 구매를 요구하지 않는다.

TabBouncer가 실행한 전용 브라우저 프로필에서 페이지와 팝업 주소, 링크·폼의 목적지, 클릭 시각과 종류, 클릭한 컨트롤의 라벨을 PC에서 처리한다. 컨트롤 라벨에는 화면의 텍스트나 컨트롤 값이 포함될 수 있다. URL에는 쿼리 문자열을 포함한 개인정보가 들어 있을 수 있다. 이러한 정보는 사용자가 요청한 탭과 자동 팝업을 구분하는 데 사용한다. 클릭 추적은 앱의 감시 동작을 위해 로컬 Chrome DevTools Protocol 연결을 통해 이루어진다.

설정, 즐겨찾기·예외 사이트, 창 상태, 차단 통계, 최근 이벤트와 진단 로그를 사용자 PC의 앱 데이터 영역에 저장한다. 이벤트와 로그에는 방문 주소, 탭을 연 페이지 주소, 판정 사유, 시각, 브라우저 버전과 파일 경로가 포함될 수 있다. 로그 파일은 크기에 따라 회전하며 최근 기록은 다음 실행 때 다시 표시될 수 있다. 전용 브라우저 프로필에는 해당 브라우저의 방문 기록, 쿠키와 사이트 데이터가 별도로 저장될 수 있다.

TabBouncer에는 개발자 서버로 정보를 전송하는 원격 분석, 광고 SDK 또는 자동 로그 업로드 기능이 없다. 사용자가 여는 웹사이트 및 Chrome·Microsoft Edge 등 브라우저의 네트워크 통신에는 해당 서비스의 개인정보 처리방침이 적용된다. Microsoft Store의 다운로드, 업데이트와 서비스 통계는 Microsoft의 정책에 따라 처리될 수 있다.

사용자는 설정 화면에서 예외·즐겨찾기 사이트를 관리하고 감시를 끌 수 있다. **로그 폴더 열기**로 저장 위치를 확인할 수 있다. 저장된 파일을 지우려면 앱과 전용 브라우저를 종료한 뒤 삭제한다. 브라우저의 쿠키와 방문 기록은 해당 브라우저의 삭제 기능으로 관리한다. 앱 제거만으로 외부 사용자 폴더에 저장된 모든 기록이 삭제된다고 보장하지 않는다.

**진단 정보 복사**는 사용자가 요청한 정보를 클립보드에 복사할 뿐 자동으로 전송하지 않는다. GitHub에 지원 요청을 작성하거나 로그를 첨부할 때는 URL의 개인정보, 로그인 토큰, 로컬 경로 등 민감한 정보를 먼저 제거해야 한다. 공개 지원 페이지는 [GitHub Issues](https://github.com/jacking75/TabBouncer/issues)다.

## English

TabBouncer is a free, open-source Windows application provided by Choi HeungBae (`jacking75`). It does not require an app account, subscription, or in-app purchase.

For the dedicated browser profile it launches, TabBouncer processes page and popup URLs, link and form destinations, click times and types, and labels of clicked controls on your PC. A control label may include visible text or a control value. URLs may contain personal information in query strings. This information helps distinguish wanted tabs from automatic popups and is exchanged through a local Chrome DevTools Protocol connection for monitoring.

Settings, favorite and exception sites, window state, block statistics, recent events, and diagnostic logs are stored in your user app-data area. Events and logs may include visited URLs, opener URLs, decision reasons, times, browser versions, and file paths. Log files rotate by size, and recent records may be displayed on later launches. The separate browser profile may also retain browser history, cookies, and site data.

TabBouncer has no developer-server analytics, advertising SDK, or automatic log-upload feature. Websites you visit and browser software such as Chrome or Microsoft Edge have their own network activity and privacy policies. Microsoft Store downloads, updates, and service statistics may be processed under Microsoft's policies.

You can manage site exceptions and favorites in settings and stop monitoring. Use **Open log folder** to locate stored files. To remove them, first close the app and its dedicated browser. Use the browser's own controls to clear cookies and history. Uninstalling the app may not remove all records saved outside its package in user folders.

**Copy diagnostics** copies requested information to the clipboard without automatically sending it. Before posting a support request or attaching logs, remove sensitive URLs, login tokens, local paths, and other private data. Public support is available through [GitHub Issues](https://github.com/jacking75/TabBouncer/issues).
